Input Templates & Least Squares Method

Field_Elevations sheet columns: RunID, Sequence, PointID, Raw_Elevation.

  • RunID: groups readings from the same leveling run.
  • Sequence: the order each point was observed inside a run (1, 2, 3, ...). Legs are built between consecutive sequence values within the same RunID.
  • PointID: point/station name.
  • Raw_Elevation: observed elevation value for that sequence record.

Control_Points sheet columns: PointID, Elevation, Fixed (Y or N).

Empty rows: allowed only as fully blank separator rows. Partially filled rows are treated as invalid input and should be completed or removed.

Least-squares formulation used in this app:

For each leg observation from point i to point j, the observation equation is built as:
Hj - Hi = ΔZobs + v
where Hi/Hj are unknown adjusted elevations (or known control if fixed), ΔZobs is the cleaned observed delta-Z, and v is the residual.

All equations are assembled in matrix form A·x - l = v, with diagonal weights from observation precision (w = 1/σ² when σ is available, otherwise 1.0). The solver computes x using normal equations:
(AᵀPA)x = AᵀPl.

Residuals are then v = A·x - l, and the solution is the one that minimizes the weighted sum of squared residuals:
vᵀPv. This gives statistically consistent adjustments while honoring fixed control constraints.
